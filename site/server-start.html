Statik Sunucu

UI yalnızca statik HTML/CSS/JS'dir. Privileged Windows Agent sunucuda çalıştırılmamalıdır.

./scripts/serve-linux-static.sh
powershell -ExecutionPolicy Bypass -File .\scripts\serve-static.ps1 -Root .\site -Port 8080
